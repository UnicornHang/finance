## Ubuntu 虚拟机 Docker 后端环境配置指引

- 目标环境明确：**Docker 跑在 Ubuntu 虚拟机上**，Windows 宿主机通过 VM IP 访问。
- 产出 `docs/ubuntu-docker-setup.md`：代码入 VM（git clone / rsync 排除 node_modules、.venv）→ Docker 前置 → `.env` 必改项 → 启动 → 验证 → 运维命令 → 排查清单。
- 顺手修的三处 Linux 兼容性问题：
  1. `scripts/*.sh`（setup / smoke / init）原本是 CRLF，拷到 Linux 会 `bad interpreter: /bin/bash^M`，已统一转 LF。
  2. `scripts/smoke.sh` 里 `PY` 写死 `python`，Ubuntu 无该命令，改为 `command -v python || command -v python3` 兜底。
  3. `backend/Dockerfile` 依赖缓存层只 COPY 了 pyproject.toml，但 `pyproject.toml` 里 `readme = "README.md"`，补 COPY README.md 防止构建元数据时找不到文件。

## 项目配置要点（重要）

- `docker-compose.yml` 把 `./backend` 挂到容器 `/app`，因此 **backend/.env 会成为容器内的 /app/.env**。目前靠「环境变量优先级 > dotenv 文件」才让根 `.env` 生效，属于隐患；建议 Docker 部署时移除 `backend/.env`（里面还带真实腾讯云 OCR 密钥）。
- `POSTGRES_HOST / REDIS_HOST / MINIO_HOST` 必须是 compose 服务名；`DATABASE_URL` 的密码必须与 `POSTGRES_PASSWORD` 同步。
- `app/services/storage_service.py` 在模块导入时就实例化 MinIO 客户端并建桶，MinIO 不通会导致 backend 启动直接失败。
- CORS 默认只允许 `http://localhost:5173`；走 nginx 80 同源不会有跨域问题，直连 8000 才需要配 `CORS_ORIGINS`（JSON 数组格式）。
