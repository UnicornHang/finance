### 选定架构：混合部署（已向用户交付方案图）
- Windows 本机：源码 + Python venv（uvicorn/celery）+ Node/Vite
- Ubuntu VM（Docker）：只跑 PostgreSQL+pgvector / Redis / MinIO 三件套
- 理由：本机 venv 已就绪、便于 IDE 断点调试；三件套内存占用小，契合宿主机内存紧张
- 连接要点：VMware NAT 下宿主机可直接访问 VM 的 NAT IP，**无需端口转发**；
  VM 建议 netplan 固定静态 IP，避免重启后 `.env` 失效

### 后续执行时的关键约束
- 后端跑的是 `backend/.env`（已含显式 `DATABASE_URL`/`REDIS_URL`），
  改 host 时**必须同步改这两条显式 URL**，否则 `config.model_post_init` 不会重算
- Ubuntu Server 安装阶段需用户在 VMware GUI 窗口手动点选（语言选 English、
  取消 LVM 勾选、必须勾选 Install OpenSSH server），SSH 打通后可由 agent 远程接管
